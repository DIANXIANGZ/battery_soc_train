# NASA 多状态电池预测设计

## 目标

在保留现有 A123#3 SOC 项目的前提下，建立独立的多任务预测流程，同时预测 SOC、SOH、SOE、RUL 与 SOT。

## 数据源与存放

使用 NASA PCoE 公开锂离子电池老化数据。原始下载文件、解析后的训练表、数据字典和划分清单均存放在 `E:\SOC电池数据中心` 的新建 NASA 多状态任务目录中，不写入或覆盖 A123#3 目录。

## 标签定义

| 输出 | 标签规则 |
| --- | --- |
| SOC | 在单次充放电轨迹内，用库仑积分得到的归一化参考荷电状态。 |
| SOH | 当前循环可用容量除以该电芯初始有效容量。 |
| SOE | 当前可释放剩余能量除以该电芯初始可释放能量。 |
| RUL | 当前循环距容量降至初始容量 70% 的剩余循环数。 |
| SOT | 数据集实际记录的温度序列；模型使用窗口末端温度作为温度状态标签，并额外记录窗口平均值、最小值和最大值以便审计。它是可测温度状态代理，不是电芯内部三维温度场。 |

标签只在来源数据足以计算时生成。无法满足容量、能量或寿命终点条件的电芯会被排除，并在审计报告中记录原因；不会用虚构值补齐。

## 数据划分与防泄漏

以电芯 ID 为最小划分单位：训练、验证、测试使用彼此不同的电芯。时间窗口不得跨循环或跨电芯。标准化参数只用训练电芯计算。测试电芯不参与任何标签阈值、采样或超参数选择。

## 模型

使用共享 LSTM 时间序列编码器和五个独立回归输出头。输入为固定长度窗口内的电压、电流、温度、时间变化与可追溯的窗口特征。每个目标单独标准化，训练损失为五个经过可用标签掩码处理的 Huber 损失加权和。输出模型同时保存特征名、目标名、标准化参数、训练划分与标签定义版本。

## 结果与平台

每次训练创建独立实验目录，保存模型、训练日志、每目标 MAE/RMSE、测试预测表和五张对比图。桌面平台新增“多状态任务”项目入口和结果展示；原 SOC 页面及现有结果保持可用。

## 失败处理与验收

下载校验文件哈希和压缩包完整性。解析阶段输出数据审计报告，必须确认每个目标有非空训练、验证和测试标签后才允许训练。验收包括：数据来源与标签可追溯、按电芯独立测试、训练完成、五个目标均输出独立测试指标及图表。
