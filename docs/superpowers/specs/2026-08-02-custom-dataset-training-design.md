# 自定义数据集与算法训练设计

## 目标

在不改变三个内置数据集行为的前提下，允许用户导入 CSV、XLSX 或 XLS 数据，映射时序、特征和一个或多个预测目标，并选择合适的训练算法。

支持的目标包括 SOC、SOE、SOT、RUL，以及任何用户数据中存在的自定义数值标签列。

## 用户流程

1. 用户在侧边栏的数据集下拉框选择“自定义数据集…”。
2. 应用打开导入窗口，选择 CSV、XLSX 或 XLS 文件；Excel 文件再选择工作表。
3. 应用读取表头，用户选择可选时间列、一个或多个特征列，以及一个或多个预测目标列。
4. 用户选择算法。默认选择 LSTM；SOC/SOE/SOT 提示 LSTM，RUL 提示 XGBoost，但用户可以改选。
5. 应用验证配置并建立一个独立的自定义项目。该项目显示在数据集下拉框中。
6. 用户在训练页设置已有训练参数并启动训练。训练日志、进度、运行目录和结果页继续使用现有体验。

## 算法范围

| 算法 | 定位 | 适用目标 |
| --- | --- | --- |
| LSTM | 默认、通用时序模型 | SOC、SOE、SOT 及其他连续时序目标 |
| GRU | 轻量时序模型 | SOC、SOE、SOT 及其他连续时序目标 |
| XGBoost | 基于窗口统计特征的表格模型 | RUL、SOH 和小型数据集 |
| Transformer | 长序列高级模型 | 数据量较大的多变量时序任务 |

首版不增加 CNN-LSTM、随机森林等相近算法，避免算法选择冗余。

## 架构与数据流

- 新增自定义数据集配置对象，保存原文件路径、工作表、列映射、目标、算法和项目名称。
- 新增数据读取与校验模块，统一读取 CSV/Excel，生成规范化的训练数据，并将配置写入自定义项目目录。
- 新增算法路由层：根据配置调用 LSTM、GRU、XGBoost 或 Transformer 的训练器；各训练器输出统一的运行目录、日志和预测结果格式。
- 桌面端只处理文件选择、列映射、算法选择和状态提示；训练仍由 `TrainingController` 在后台子进程执行。
- 内置数据集仍沿用现有命令构造和训练脚本，不经过自定义数据的路由层。

## 校验与错误处理

- 拒绝不支持的文件格式、空文件和无法读取的工作表。
- 必须选择至少一个特征列和一个目标列。
- 特征和目标必须能转换为数值；时间列可选。
- 训练前检查去除缺失值后剩余样本量足以按窗口切分；错误信息指出具体列或原因。
- 多目标训练仅在所选算法支持时启用；不支持时在导入窗口明确提示，不能启动训练。

## 验收与测试

- CSV、XLSX、XLS 均可载入表头；Excel 可选择工作表。
- 列映射和自定义项目配置可持久化并在重启后重新出现。
- 算法选择能被正确路由：LSTM、GRU、XGBoost、Transformer。
- 无效文件、缺列、非数值数据和样本不足有可读错误信息。
- 原有内置数据集、训练命令和桌面端测试保持通过。

## 非目标

- 首版不自动搜索最佳算法或自动调参。
- 首版不支持非结构化数据、在线数据源或分类任务。
