# macOS Finder 风格桌面界面：设计说明

## 目标

将 Tkinter 桌面平台重构为接近 macOS Finder 的浅色工作台：固定侧栏、轻量工具栏、宽松的主内容分组和舒适的按钮间距。训练、数据、项目与结果处理逻辑保持不变。

## 结构

- 左侧固定导航：项目选择、项目概览、数据集、训练方案、实验结果和数据中心入口。
- 右侧主内容：仅该区域可滚动；标题、说明、表单、提示、主要操作和日志均处在统一的宽松内容栅格内。
- 顶部：保留系统窗口标题栏；应用内部使用简洁工具栏，不仿制 macOS 的系统按钮。

## 视觉规则

- 背景使用极浅的蓝绿色调，白灰仅作为表单和图表的局部底色；移除当前暖黄色画布与深紫色大面积侧栏。
- 侧栏采用深青蓝，当前项目和当前页面使用湖蓝选中态；导航悬停使用低饱和青绿。
- 主操作使用青绿色；次级强调、标签与选中态使用湖蓝；错误和危险操作保留红色语义，成功状态使用绿色。
- 表单、结果和图表使用 12–14px 圆角、细边线、极弱阴影或无阴影。
- 标题使用清晰的深色层级；说明文字使用中灰；不使用大面积高饱和色。
- 参数输入行增加垂直间距；训练按钮下方与日志区之间至少留出一个独立操作间隔。

## 交互与滚动

- 鼠标位于右侧内容区时，滚轮滚动右侧内容；左侧导航保持固定。
- 右侧滚动条始终与内容同步，在窗口高度不足时能访问训练按钮、进度与日志。
- 窄窗口下保留当前的两列参数布局和水平可读性，不改变字段、默认值或训练命令。

## 安全与验证

- 不修改训练参数含义、默认值、数据路径、运行目录、模型代码或删除保护。
- 新增主题仅集中在 `src/desktop/theme.py` 与 `src/desktop/app.py` 的布局和样式调用。
- 为主题色、侧栏布局、滚动行为和原始内容边距添加回归测试。
- 使用 `py_compile` 和完整 unittest 测试集验证重构后训练逻辑未回归。
